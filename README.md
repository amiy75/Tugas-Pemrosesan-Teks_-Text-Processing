# Tugas-Pemrosesan-Teks_-Text-Processing
## Deskripsi
menggunakan data artikel dari Quanta Magazine kategori Physics.Data diperoleh melalui proses web scraping kemudian dilanjutkan dengan preprocessing teks.
## Tahapan Pemrosesan
1. Web Scraping
2. Case Folding
3. Cleaning
4. Tokenization
5. Stopword Removal
6. Lemmatization
7. Analisis Frekuensi Kata
8. Word Cloud
9. Bar Chart 20 Kata Terbanyak

## Dataset
Data Mentah = 'quanta_physics_articles.csv'
Data hasil Processing.csv = 'quanta_physics_full_preprocessing.csv'

## Notebook
Proses scraping, preprocessing, dan analisis dilakukan menggunakan
Google Colab dan disimpan dalam file:'Text_Processing_QuantaMagazine.ipynb'
